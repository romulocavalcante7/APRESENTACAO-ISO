# Dicionário em palavras simples

Use para estudar e para explicar. Cada termo tem uma frase fácil e um jeito de falar na aula.

| Palavra | Quer dizer | Diga assim |
|---|---|---|
| Ativo | Qualquer coisa que tem valor para a empresa | "O que a gente precisa proteger" |
| Ameaça | O que pode causar dano | "Quem ou o que pode atrapalhar" |
| Vulnerabilidade | Ponto fraco | "A janela aberta" |
| Risco | Chance de dar problema vezes o tamanho do estrago | "O quanto vale se preocupar" |
| Risco residual | O risco que sobra depois dos controles | "O que ainda resta" |
| Controle | Medida para diminuir o risco | "A fechadura" |
| SGSI | Sistema de gestão de segurança da informação | "O jeito organizado da empresa cuidar da segurança" |
| Norma | Documento com regras e boas práticas combinadas por especialistas | "Um manual aceito por todos" |
| Requisito | Algo que a norma exige | "O que tem que ser feito" |
| Diretriz | Recomendação, orientação | "O que se aconselha" |
| Certificação | Prova de que a empresa segue a norma, dada por um auditor independente | "A carteira de motorista da empresa" |
| Organismo certificador | A empresa que audita e dá o certificado | "O examinador" |
| Acreditação | Reconhecimento de que o certificador é competente | "A autorização do examinador" |
| Auditoria | Conferência feita por alguém para ver se o combinado é cumprido | "A prova" |
| Não conformidade | Algo que não cumpre a norma | "Um erro apontado pelo auditor" |
| Escopo | O que está dentro do sistema | "O pedaço da empresa que a gente protege" |
| SoA | Lista dos controles escolhidos, com a razão da escolha | "A lista de quais controles usamos e por quê" |
| PDCA | Planejar, fazer, conferir, agir | "O ciclo da melhoria" |
| Evidência | Prova de que algo foi feito | "O registro com data" |
| Indicador | Número com meta para medir se algo funciona | "O placar" |
| Meta | O valor que a empresa quer atingir | "A nota que queremos tirar" |
| Accountability | Prestar contas, ter responsável e prova | "Quem responde e como prova" |
| MFA | Login com mais de uma forma de provar quem você é | "Senha mais um código" |
| RBAC | Acesso por cargo | "A chave vem do cargo" |
| PAM | Controle das contas de administrador | "Cuidar de quem tem a chave mestra" |
| Menor privilégio | Cada pessoa tem só o acesso necessário | "Nem mais, nem menos" |
| Log | Registro automático do que aconteceu | "O caderno de ocorrências do sistema" |
| Criptografia | Embaralhar o dado para que só a chave o leia | "O cadeado do dado" |
| TLS / HTTPS | Proteção do dado enquanto viaja pela internet | "O cadeado do navegador" |
| AES-256 | Tipo de criptografia usada em dado guardado | "O cofre" |
| Chave | Segredo usado para trancar e destrancar | "A chave do cadeado" |
| Rotação de chaves | Trocar a chave de tempos em tempos | "Trocar a fechadura" |
| Backup | Cópia dos dados | "A cópia de segurança" |
| 3-2-1 | 3 cópias, 2 tipos de mídia, 1 fora do local | "Não coloque todos os ovos na mesma cesta" |
| Ransomware | Programa que sequestra dados e pede resgate | "O sequestro de dados" |
| Redundância | Ter um reserva | "O estepe" |
| Failover | Troca automática para o reserva | "O estepe entrando sozinho" |
| DR | Plano para recuperar depois de um desastre | "O plano B" |
| RTO | Tempo máximo que se aceita ficar parado | "Quanto tempo posso ficar fora do ar" |
| RPO | Quantidade máxima de dado que se aceita perder | "Até que momento o backup me traz de volta" |
| LGPD | Lei brasileira de proteção de dados pessoais | "A lei dos dados pessoais" |
| ANPD | Autoridade que fiscaliza a LGPD | "O órgão que fiscaliza" |
| MTTD / MTTR | Tempo médio para detectar / para responder | "Quanto demora para perceber e para resolver" |
| Inmetro | Órgão brasileiro que acredita certificadores | "Quem autoriza os examinadores" |
| PME | Pequena e média empresa | "Empresa pequena" |

## Como explicar um termo difícil (método rápido)

1. Diga o nome do termo.
2. Dê a frase fácil da tabela.
3. Dê um exemplo do dia a dia (celular, casa, faculdade).
4. Só depois diga o termo técnico completo.
Exemplo: "Backup 3-2-1. Quer dizer ter três cópias, em dois tipos de lugar, e uma delas longe. Igual às fotos do celular: no celular, na nuvem e no HD de casa."
